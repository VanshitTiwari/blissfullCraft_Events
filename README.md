# Vespera Events

Full-stack event organiser website: public studio site plus an admin dashboard for events and enquiries.

## Run locally

```bash
npm run install:all
npm run dev
```

- Site: http://localhost:5173
- API: http://localhost:5050

## Admin

- URL: http://localhost:5173/admin
- Email: `admin@vespera.events`
- Password: `vespera2026`

## Stack

- React + Vite frontend
- Express REST API
- JSON file store at `server/data/db.json` (created on first run)
